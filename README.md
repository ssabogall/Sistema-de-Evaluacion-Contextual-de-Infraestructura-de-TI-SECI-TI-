# Sistema-de-Evaluaci-n-Contextual-de-Infraestructura-de-TI-SECI-TI-
Context-aware IT infrastructure analysis and recommendation system for evaluating and improving architectures based on business requirements and constraints.

CETI - TI is a system designed to analyze IT infrastructure in the context of specific business and application requirements. It identifies infrastructure needs, evaluates existing architectures, and provides actionable recommendations for improvement based on established architecture principles, quality attributes, metrics, and infrastructure best practices.
